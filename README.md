# StratCraft

StratCraft is a Python package for strategy and metrics analysis. It provides useful utilities, decorators, and metrics functions for data science and machine learning workflows.

## Features
- Decorators for timing and function profiling
- Standard metrics for regression analysis
- Utility functions for data manipulation

## Installation

You can install StratCraft locally using:

```bash
pip install .
```

## Usage

Import the package and use its modules:

```python
from stratcraft import timing, mean_absolute_error, mean_squared_error
```
